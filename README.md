# 🌱 কৃষি সাথী এআই (AgriSathi AI) — Smart Agricultural Assistant

কৃষি সাথী এআই হলো একটি আধুনিক ও পূর্ণাঙ্গ দ্বিভাষিক (বাংলা ও ইংরেজি) কৃত্রিম বুদ্ধিমত্তা ভিত্তিক কৃষি সহায়ক অ্যাপ্লিকেশন। এটি কৃষক, কৃষিবিদ এবং বাগানপ্রেমীদের জন্য ফসলের রোগবালাই নির্ণয়, সার ক্যালকুলেটর, মৌসুমি পরামর্শ এবং মুক্ত কৃষি প্রশ্নোত্তর সেবা প্রদান করে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### 1. 💬 দ্বিভাষিক এআই কৃষি পরামর্শক (Bilingual AI Agri Chat)
- **বাংলা ও ইংরেজি সমর্থন:** এক ক্লিকে সম্পূর্ণ ইন্টারফেস ও উত্তরের ভাষা পরিবর্তন (বাংলা / English)।
- **কৃষি বিষয়ক যে কোনো প্রশ্নের উত্তর:** ধান, গম, আলু, ভুট্টা, পাট, সরিষা, শাকসবজি এবং ফলমূল চাষাবাদ সংক্রান্ত যে কোনো প্রশ্ন।
- **ক্লিকযোগ্য কুইক প্রম্পট:** সাধারণ সমস্যাগুলোর জন্য দ্রুত প্রশ্ন করার সুবিধা।

### 2. 🔍 ফসলের রোগ ও বালাই নির্ণয় (Disease & Pest Diagnostic)
- ফসল নির্বাচন এবং দৃশ্যমান লক্ষণের ভিত্তিতে রোগ শনাক্তকরণ।
- গাছের পাতার ছবি আপলোডের সুবিধা।
- **সুনির্দিষ্ট প্রতিকার:** রাসায়নিক ওষুধ ও সঠিক ডোজের পাশাপাশি পরিবেশবান্ধব জৈব সমাধান।

### 3. ⚖️ স্মার্ট সার ক্যালকুলেটর (Precision Fertilizer Calculator)
- বাংলাদেশ কৃষি গবেষণা কাউন্সিল (BARC) অনুমোদিত ফর্মুলা অনুযায়ী।
- জমির পরিমাণ (শতক, কাঠা, বিঘা, একর, হেক্টর) দিলে স্বয়ংক্রিয়ভাবে ইউরিয়া, টিএসপি/ডিএপি, এমওপি (পটাশ), জিপসাম, জিংক ও গোবরের সঠিক কেজি পরিমাণ হিসাব।
- কোন কিস্তিতে কতটুকু সার প্রয়োগ করতে হবে তার সুস্পষ্ট সময়সূচি।

### 4. 📅 মৌসুমি ফসল ক্যালেন্ডার ও জৈব বালাইনাশক (Crop Calendar & Organic Solutions)
- রবি (শীতকাল), খরিফ-১ (গ্রীষ্মকাল) এবং খরিফ-২ (বর্ষাকাল) এর ফসল ও আবহাওয়া নির্দেশিকা।
- ঘরে বসে নিম তেলের স্প্রে, রসুন-মরিচ নির্যাস এবং ট্রাইকোডার্মা জৈব বালাইনাশক তৈরির প্রণালী।

### 5. ⚡ মাল্টি-মডেল এআই ইঞ্জিন (Multi-Engine Support)
- **🟢 অফলাইন এগ্রি এক্সপার্ট (Local Expert):** কোনো API Key ছাড়াই তাৎক্ষণিকভাবে কাজ করে।
- **⚡ Groq Cloud (Llama 3.3 70B):** অতি দ্রুত ও নির্ভুল (ফ্রি API Key সাপোর্ট)।
- **✨ Google Gemini API:** Gemini 2.5 / 1.5 Flash সাপোর্ট (ফ্রি API Key সাপোর্ট)।
- সরাসরি অ্যাপের ভেতরে সেটিংস ট্যাব থেকে ১ ক্লিকে এপিআই কি সেভ করার সুবিধা।

## 🚀 যেভাবে চালাবেন (How to Run)

### পদ্ধতি ১: ডাবল ক্লিকে চালু (Windows)
ফোল্ডারে থাকা `run_app.bat` ফাইলে ডাবল ক্লিক করুন।

### পদ্ধতি ২: টার্মিনাল বা কমান্ড প্রম্পটে
```bash
cd "d:\Agri AI App"
python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
ব্রাউজারে ওপেন হবে: `http://localhost:8501`

## 📱 মোবাইলে যেভাবে ব্যবহার করবেন (Mobile Guide)

### ধাপ ১: একই Wi-Fi বা Hotspot সংযোগ
আপনার কম্পিউটার এবং মোবাইল ফোন একই Wi-Fi রাউটারে কানেক্ট করুন (অথবা মোবাইলের Hotspot চালু করে কম্পিউটারে কানেক্ট করুন)।

### ধাপ ২: কম্পিউটারে অ্যাপটি চালু করুন
`run_app.bat` ফাইলটিতে ডাবল ক্লিক করুন। টার্মিনালে দুটি লিংক দেখতে পাবেন:
- **Local URL:** `http://localhost:8501`
- **Network URL:** `http://192.168.x.x:8501` (আপনার কম্পিউটারের লোকাল আইপি)

### ধাপ ৩: মোবাইলের ব্রাউজারে প্রবেশ করুন
মোবাইলের Chrome বা Safari ব্রাউজার ওপেন করে **Network URL** টি লিখুন (যেমন: `http://192.168.31.1:8501`)। সম্পূর্ণ অ্যাপটি মোবাইল স্ক্রিনে ওপেন হবে।

### ধাপ ৪: মোবাইলের হোম স্ক্রিনে অ্যাপ আইকন যুক্ত করুন (PWA App Shortcut)
1. মোবাইলের Chrome ব্রাউজারের উপরে ডানদিকের **৩-ডট (⋮)** মেনুতে চাপ দিন।
2. **"Add to Home screen"** অথবা **"ইনস্টল করুন / Install app"** এ ক্লিক করুন।
3. আপনার ফোনে সাধারণ অ্যান্ড্রয়েড বা আইওএস অ্যাপের মতো **"কৃষি সাথী"** আইকন চলে আসবে, যেখান থেকে এক ক্লিকে ফুল-স্ক্রিনে অ্যাপটি চলবে!

অ্যাপটি অফলাইন বিল্ট-ইন মোডেই সুন্দরভাবে কাজ করে। আপনি যদি ওপেন-এন্ডেড জেনারেটিভ এআই ব্যবহার করতে চান:

2. **Google Gemini:**
   - যান: [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
   - বিনামূল্যে Gemini API Key তৈরি করে অ্যাপের Settings ট্যাবে সংরক্ষণ করুন।
